## F1 fold-computed

**In plain English.** F1 fold-computed: given fewer than 2^32 facts and three arrays as long as the facts to work in (what the arrays held before does not matter), Fold gives one of two answers. Unfit, naming the position of a fact whose invocation or entry number is negative or not below the number of facts. Otherwise exactly what Project answers for the history the facts stand for: the same refusal at the same position, or one cell for each invocation state, in the same order, standing for that state.

```dafny
method Fold(facts: seq<Fact>, cells: array<Cell>, slots: array<Index>, entries: array<bool>) returns (out: Folding)
  requires |facts| < 0x1_0000_0000 && cells.Length == |facts| && slots.Length == |facts| && entries.Length == |facts|
  modifies cells, slots, entries
  ensures out.Unfit? ==> 0 <= out.at as int < |facts| && !Fit(facts[out.at], |facts|)
  ensures !out.Unfit? ==> Agrees(out, facts)
```

## World-model assumptions (requirements on the shell and stores; not proven here)

- **A1** the facts are the receipts invocationReceipts parsed from the session branch, in branch order. The shell numbers invocations and canonical entries from 0 in order of first appearance, so every number is below the number of receipts. A start receipt is stated as owned, with name mark Same when it carries a name (else Absent) and origin mark Same (its origin being the default origin of its source when it carries none). A later receipt is owned exactly when its operation and source equal those of the first start receipt of its invocation before it; its name mark is Absent when it carries no name, Same when its name is that start's and Differs otherwise, and its origin mark likewise (origins compared by canonical JSON). A receipt with no start before it is refused whatever its marks say. The fold reads any facts the way Project reads the receipts they stand for (law F1), so its laws do not depend on A1; A1 is what the facts mean. In the receipt grammar only a binding carries a canonical entry and only a terminal a retryable flag or, besides a start, a name or an origin.
- **A2** a cell's start position is the position of its invocation's start receipt (law F1: the cell stands for the state StepOf built from that receipt). The shell reads everything a projection takes from the start there: its identity, operation, source, name, arguments, resources, submitted text, origin and sequence; it reads the canonical entry from the receipt at entryAt and the time from the receipt at updated, and orders the result by start sequence (a stable sort, ties in start order), as invocationProjection does; the block returns invocations in start order. TerminalLife: completed, failed, interrupted and outcome-unknown are settled; nothing follows them.

## Implementation under test (compiled to JS; the laws constrain these)

```dafny
predicate Legal(from: Life, to: MaybeLife, settle: bool) {
  if TerminalLife(from) || to.NoLife? then false
  else if settle then TerminalLife(to.l)
  else
    var t := to.l;
    match from
    case Staged => t.Accepted? || t.Queued? || t.Running? || t.WaitingForInput? || t.Retrying? || t.Settling?
    case Accepted => t.Queued? || t.Running? || t.WaitingForInput? || t.Retrying? || t.Settling?
    case Queued => t.Running? || t.Settling?
    case Running => t.WaitingForInput? || t.Retrying? || t.Settling?
    case WaitingForInput => t.Running? || t.Settling?
    case Retrying => t.Running? || t.Settling?
    case _ => false
}
```

```dafny
predicate Repeats(to: MaybeLife, settled: Life) {
  to.LifeOf? && ((to.l.Staged? && settled.Staged?) || (to.l.Accepted? && settled.Accepted?) || (to.l.Queued? && settled.Queued?)
    || (to.l.Running? && settled.Running?) || (to.l.WaitingForInput? && settled.WaitingForInput?) || (to.l.Retrying? && settled.Retrying?)
    || (to.l.Settling? && settled.Settling?) || (to.l.Completed? && settled.Completed?) || (to.l.Failed? && settled.Failed?)
    || (to.l.Interrupted? && settled.Interrupted?) || (to.l.OutcomeUnknown? && settled.OutcomeUnknown?))
}
```

```dafny
predicate Changed(mark: Mark, start: Mark) { (mark.Same? && !start.Same?) || (mark.Differs? && !start.Differs?) }
```

```dafny
function Begin(f: Fact, k: Index): Cell { Cell(k, if f.life.LifeOf? then f.life.l else Accepted, false, false, -1, NoFlag, k) }
```

```dafny
function Advance(s: Fact, p: Cell, f: Fact, k: Index, entryBound: bool): Verdict {
  if s.owned != f.owned then Refuse(OwnershipChanged)
  else if f.kind.Binding? && entryBound then Refuse(EntryBound)
  else if f.kind.Binding? && p.bound then Refuse(InvocationBound)
  else if Changed(f.name, s.name) then Refuse(NameChanged)
  else if Changed(f.origin, s.origin) then Refuse(OriginChanged)
  else if f.kind.Terminal? && p.settled && !Repeats(f.life, p.life) then Refuse(ContradictoryTerminal)
  else if f.kind.Terminal? && !p.settled && !Legal(p.life, f.life, true) then Refuse(IllegalTerminal)
  else if f.kind.Transition? && !Legal(p.life, f.life, false) then Refuse(IllegalTransition)
  else
    var settled := p.settled || f.kind.Terminal?;
    Accept(Cell(p.start, if f.life.LifeOf? && (f.kind.Terminal? || !settled) then f.life.l else p.life, settled,
      p.bound || f.kind.Binding?, if f.entry.IndexOf? then k else p.entryAt, if f.retryable.FlagOf? then f.retryable else p.retryable, k))
}
```

## Definitions the laws use

**Fit**: Fit: the fact's invocation number, and its entry number if it has one, is at least 0 and below n.

```dafny
ghost predicate Fit(f: Fact, n: int) { 0 <= f.inv as int < n && (f.entry.IndexOf? ==> 0 <= f.entry.i as int < n) }
```

**Agrees**: Agrees: the answer is Project's for the history the facts stand for: the same refusal at the same position, or one cell for each invocation state, in the same order, standing for it.

```dafny
ghost predicate Agrees(out: Folding, fs: seq<Fact>) {
  var rs := ReceiptsOf(fs);
  match Project(rs)
  case Rejected(why, at) => out.Stopped? && out.why == why && out.at as int == at
  case Projected(projs) => (out.Finished? && |Elems(out.cells)| == |projs|
    && forall i | 0 <= i < |projs| :: Placed(Elems(out.cells)[i], rs) && ProjOf(Elems(out.cells)[i], rs) == projs[i])
}
```

**ReceiptsOf**: ReceiptsOf: the history the facts stand for.

```dafny
ghost function ReceiptsOf(fs: seq<Fact>): seq<Receipt> { seq(|fs|, k requires 0 <= k < |fs| => ReceiptOf(fs[k], k)) }
```

**Project**: Project: the receipts of one session folded one after another from no invocations: the invocations' states in start order, or the first refusal.

```dafny
ghost function Project(rs: seq<Receipt>): Outcome { Run(State([], [], []), rs, 0) }
```

**Run**: Run: the receipts folded one after another from the state, positions counted from k; the first refused receipt refuses the whole history, naming its position.

```dafny
ghost function Run(st: State, rs: seq<Receipt>, k: int): Outcome
  decreases |rs|
{
  if |rs| == 0 then Projected(st.projs)
  else match StepOf(st, rs[0])
    case Refused(why) => Rejected(why, k)
    case Next(st2) => Run(st2, rs[1..], k + 1)
```

**Elems**: Elems: the items of a linked list, in order.

```dafny
ghost function Elems<T>(l: List<T>): seq<T> { if l.Nil? then [] else [l.head] + Elems(l.tail) }
```

**Placed**: Placed: the cell's positions are positions of the history (entryAt and none: -1).

```dafny
ghost predicate Placed(c: Cell, rs: seq<Receipt>) { 0 <= c.start as int < |rs| && c.entryAt as int < |rs| && 0 <= c.updated as int < |rs| }
```

**ProjOf**: ProjOf: the invocation state a cell stands for: identity, name, origin and sequence of the receipt at its start; the entry of the receipt at entryAt; its position `updated` as its time.

```dafny
ghost function ProjOf(c: Cell, rs: seq<Receipt>): Proj
  requires Placed(c, rs) {
  var s := rs[c.start];
  Proj(s.inv, s.op, s.src, s.name, s.origin, c.life, if c.entryAt >= 0 then rs[c.entryAt].entry else None, c.retryable,
    s.sequence, c.updated as int, c.settled)
}
```

**StepOf**: StepOf: one receipt folded into the state. A start appends its invocation's state, or is refused when the invocation has one. A later receipt is refused when its invocation has no start, and otherwise for the first check it fails: ownership, an entry already bound, an invocation already bound, another name, another origin, a contradictory terminal, an illegal terminal, an illegal transition; when it passes them all it updates its invocation's state, and a binding records its entry and invocation as bound.

```dafny
ghost function StepOf(st: State, r: Receipt): Step {
  var i := FindIndex(st.projs, r.inv);
  if r.kind.Start? then
    if i >= 0 then Refused(DuplicateStart)
    else Next(st.(projs := st.projs + [Proj(r.inv, r.op, r.src, r.name, r.origin,
      if r.life.LifeOf? then r.life.l else Accepted, None, NoFlag, r.sequence, r.at, false)]))
  else if i < 0 then Refused(NoStart)
  else
    var p := st.projs[i];
    if p.op != r.op || p.src != r.src then Refused(OwnershipChanged)
    else if r.kind.Binding? && r.entry in st.entries then Refused(EntryBound)
    else if r.kind.Binding? && r.inv in st.bound then Refused(InvocationBound)
    else if r.name.Some? && r.name != p.name then Refused(NameChanged)
    else if r.origin.Some? && r.origin != p.origin then Refused(OriginChanged)
    else if r.kind.Terminal? && p.terminal && r.life != LifeOf(p.life) then Refused(ContradictoryTerminal)
    else if r.kind.Terminal? && !p.terminal && !Legal(p.life, r.life, true) then Refused(IllegalTerminal)
    else if r.kind.Transition? && !Legal(p.life, r.life, false) then Refused(IllegalTransition)
    else
      var settled := p.terminal || r.kind.Terminal?;
      Next(State(st.projs[i := p.(
          life := if r.life.LifeOf? && (r.kind.Terminal? || !settled) then r.life.l else p.life,
          entry := if r.entry.Some? then r.entry else p.entry,
          retryable := if r.retryable.FlagOf? then r.retryable else p.retryable,
          updated := r.at, terminal := settled)],
        if r.kind.Binding? then st.entries + [r.entry] else st.entries,
        if r.kind.Binding? then st.bound + [r.inv] else st.bound))
}
```

**FindIndex**: The index of the first state of invocation inv, or -1.

```dafny
ghost function FindIndex(projs: seq<Proj>, inv: int): int
  decreases |projs|
  ensures -1 <= FindIndex(projs, inv) < |projs|
{
  if |projs| == 0 then -1
  else if projs[0].inv == inv then 0
  else var k := FindIndex(projs[1..], inv); if k < 0 then -1 else k + 1
```

**Held**: Held: cell c is the fold's cell for the state's i-th invocation, with positions before k: it stands for that invocation's state, says whether the invocation is bound, and no other state is of the same invocation.

```dafny
ghost predicate Held(c: Cell, st: State, i: int, rs: seq<Receipt>, k: int)
  requires 0 <= i < |st.projs|
{
  Placed(c, rs) && c.start as int < k && c.entryAt as int < k && c.updated as int < k
  && ProjOf(c, rs) == st.projs[i]
  && c.bound == (st.projs[i].inv in st.bound)
  && FindIndex(st.projs, st.projs[i].inv) == i
```

**TerminalLife**: TerminalLife: completed, failed, interrupted and outcome-unknown are settled; nothing follows them.

**Allowed**: Allowed: the lifecycle moves a transition receipt may make (a terminal receipt may settle any unsettled one).

```dafny
ghost predicate Allowed(from: Life, to: Life) {
  match from
  case Staged => to in {Accepted, Queued, Running, WaitingForInput, Retrying, Settling}
  case Accepted => to in {Queued, Running, WaitingForInput, Retrying, Settling}
  case Queued => to in {Running, Settling}
  case Running => to in {WaitingForInput, Retrying, Settling}
  case WaitingForInput => to in {Running, Settling}
  case Retrying => to in {Running, Settling}
  case _ => false
}
```

**Seen**: Seen: the state already holds invocation inv (its start was folded).

**Check**: Check: the checks a later receipt for a started invocation p must pass, in this order: the same operation and source as the start; for a binding, an entry not yet bound and an invocation not yet bound; no resource name other than the start's; no origin other than the start's.

```dafny
ghost function Check(st: State, r: Receipt, p: Proj): Checked {
  if p.op != r.op || p.src != r.src then Fails(OwnershipChanged)
  else if r.kind.Binding? && r.entry in st.entries then Fails(EntryBound)
  else if r.kind.Binding? && r.inv in st.bound then Fails(InvocationBound)
  else if r.name.Some? && r.name != p.name then Fails(NameChanged)
  else if r.origin.Some? && r.origin != p.origin then Fails(OriginChanged)
  else Passes
}
```
