**Mods**: Mods: the tools after applying the modifiers of entries, in order, to tools: a plain entry changes nothing, +name appends the tool when it is not listed and its name is not empty, -name removes its first occurrence.

```dafny
ghost function Mods(tools: seq<Token>, entries: seq<Entry>): seq<Token>
  decreases |entries|
{

  else

      case Plain(_) => tools
      case Plus(n) => if n != 0 && n !in tools then tools + [n] else tools
      case Minus(n) => RemoveFirst(tools, n);
    Mods(next, entries[1..])
```

**StepSeq**: The tools after one entry, as Mods steps.

```dafny
ghost function StepSeq(tools: seq<Token>, e: Entry): seq<Token> {

  case Plain(_) => tools
  case Plus(n) => if n != 0 && n !in tools then tools + [n] else tools
```
