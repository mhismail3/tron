**Encode**: Encode: what a layer holds after the user chooses `chosen`, given the selection below it and what it holds now: the choice as it is when it holds a modifier or the layer holds a plain name; otherwise the modifiers that turn the selection below (or the defaults) into the choice when they reproduce it, nothing when none is needed, and the choice as it is when they cannot reproduce its order.

```dafny
ghost function Encode(chosen: seq<Entry>, below: Below, current: seq<Entry>, defaults: seq<Token>): Held {
  if exists i | 0 <= i < |chosen| :: IsModifier(chosen[i]) then Holds(chosen)
  else if !AllModifiers(current) then Holds(chosen)
  else
    var base := if below.Names? then below.names else defaults;
    var delta := Delta(Plains(chosen), base);
    if Mods(base, delta) != Plains(chosen) then Holds(chosen)
    else if |delta| > 0 then Holds(delta) else Nothing
}
```

**IsModifier**: IsModifier: the entry adds or removes a tool.

```dafny
predicate IsModifier(e: Entry) { e.Plus? || e.Minus? }
```

**AllModifiers**: AllModifiers: every entry adds or removes a tool (true of no entries).

```dafny
ghost predicate AllModifiers(es: seq<Entry>) { forall i | 0 <= i < |es| :: IsModifier(es[i]) }
```

**Delta**: Delta: the modifiers that turn `base` into `chosen` when that is possible: an add for each chosen name not in base, in chosen order, then a remove for each base name not chosen, in base order.

```dafny
ghost function Delta(chosen: seq<Token>, base: seq<Token>): seq<Entry> {
  seq(|Adds(chosen, base)|, i requires 0 <= i < |Adds(chosen, base)| => Plus(Adds(chosen, base)[i]))
  + seq(|Adds(base, chosen)|, i requires 0 <= i < |Adds(base, chosen)| => Minus(Adds(base, chosen)[i]))
```

**Decide**: What a layer holds, from the three facts Encode and EncodeList decide by.

```dafny
ghost function Decide(holdsModifier: bool, holdsPlain: bool, reproduced: bool, chosen: seq<Entry>, delta: seq<Entry>): Held {
  if holdsModifier || holdsPlain || !reproduced then Holds(chosen)
  else if |delta| > 0 then Holds(delta) else Nothing
}
```

**Marked**: An add (plus) or a remove of each name, in order.

```dafny
ghost function Marked(names: seq<Token>, plus: bool): seq<Entry> {
  seq(|names|, i requires 0 <= i < |names| => if plus then Plus(names[i]) else Minus(names[i]))
```

**Adds**: Adds: the names of a that are not in b, in a's order (repeats kept).

```dafny
ghost function Adds(a: seq<Token>, b: seq<Token>): seq<Token>

{ if |a| == 0 then [] else (if a[0] in b then [] else [a[0]]) + Adds(a[1..], b) }
```
