## World-model assumptions (requirements on the shell and stores; not proven here)

- **A1** in one call the shell gives each value it reads its own token (a layer's per-model value and its plain value are two tokens), the default value token 0, and turns a Compose term into a value by calling the setting type's own compose. The block decides which values take part and in what order; it never sees, compares or combines values, so whether two tokens stand for equal values changes no decision.

```dafny
predicate Admitted(k: Key, l: Layer) {
  match l
  case Global => true
  case Home => k.sessionOverridable
  case Session => k.sessionOverridable
  case Project => k.projectSettable
}
```

```dafny
function ShownOf(k: Key, ls: Layers, l: Layer): Shown {
  var e := At(ls, l);
  if !e.inTarget then Hidden
  else if !e.bound then Hidden
  else if !Admitted(k, l) then Hidden
  else if e.qualified.Some? then Shown(true, e.qualified.v, e.applied)
  else if e.unqualified.Some? then Shown(false, e.unqualified.v, e.applied)
  else Hidden
}
```

```dafny
function Over(k: Key, s: Shown, l: Layer, below: Won): Won {
  if s.Shown? && s.applied then Won(if k.composes then Compose(below.value, s.token) else Tok(s.token), FromLayer(l))
  else below
}
```

```dafny
function Top(s: Shown, l: Layer, below: Unapplied): Unapplied {
  if !s.Shown? then below else if s.applied then AllApplied else Unapplied(l)
}
```

```dafny
function Resolve(k: Key, ls: Layers): Resolution {
  var g, h, s, p := ShownOf(k, ls, Global), ShownOf(k, ls, Home), ShownOf(k, ls, Session), ShownOf(k, ls, Project);
  var won := Over(k, p, Project, Over(k, s, Session, Over(k, h, Home, Over(k, g, Global, Won(Default, FromDefault)))));
  Resolution(won.value, won.layer, Top(p, Project, Top(s, Session, Top(h, Home, Top(g, Global, AllApplied)))), Shows(g, h, s, p))
}
```

```dafny
function PlainOver(k: Key, ls: Layers, m: Layer, below: bool, v: Value): Value {
  var e := At(ls, m);
  if !below then v
  else if !e.inTarget then v
  else if !e.bound then v
  else if !Admitted(k, m) then v
  else if !e.applied then v
  else if e.unqualified.None? then v
  else if k.composes then Compose(v, e.unqualified.v) else Tok(e.unqualified.v)
}
```

```dafny
function Below(k: Key, ls: Layers, l: Layer): Value {
  PlainOver(k, ls, Session, l.Project?,
    PlainOver(k, ls, Home, l.Session? || l.Project?,
      PlainOver(k, ls, Global, !l.Global?, Default)))
}
```

## Definitions the laws use

**Live**: Live: layer l takes part and is applied.

```dafny
ghost predicate Live(k: Key, ls: Layers, l: Layer) { Visible(k, ls, l) && At(ls, l).applied }
```

**Visible**: Visible: layer l takes part: the target has it, the setting is stored there, the declaration admits it, and the layer holds a per-model or plain value.

```dafny
ghost predicate Visible(k: Key, ls: Layers, l: Layer) {
  var e := At(ls, l);
  e.inTarget && e.bound && Admitted(k, l) && (e.qualified.Some? || e.unqualified.Some?)
}
```

**At**: The entry the layers hold for layer l.

```dafny

  match l
  case Global => ls.global

  case Session => ls.session
  case Project => ls.project
```

**Rank**: Rank: the precedence order, Global 1 < Home 2 < Session 3 < Project 4 (Project above Session, decided by Mohsin, H1); the default is below every layer.

**StepL**: The state after layer l: an applied layer that takes part sets the value and the origin.


**Step**: Step: the value after one more applied layer: the layer's value composed with the value below it for a composing setting, else the layer's value alone.

```dafny
ghost function Step(k: Key, below: Value, t: Token): Value { if k.composes then Compose(below, t) else Tok(t) }
```

**Folded**: Folded: the value after applied layers with tokens ts, lowest first, starting from v.

```dafny
ghost function Folded(k: Key, v: Value, ts: seq<Token>): Value
  decreases |ts|
{ if |ts| == 0 then v else Folded(k, Step(k, v, ts[0]), ts[1..]) }
```

**LiveTokens**: The tokens of the applied layers that take part, lowest first.

```dafny
ghost function LiveTokens(k: Key, ls: Layers): seq<Token> {
  (if Live(k, ls, Global) then [TokenOf(ls.global)] else [])
  + (if Live(k, ls, Home) then [TokenOf(ls.home)] else [])
  + (if Live(k, ls, Session) then [TokenOf(ls.session)] else [])
  + (if Live(k, ls, Project) then [TokenOf(ls.project)] else [])
```

**BelowTokens**: The plain-value tokens of the applied, admitted layers strictly below l that are in the target, bound and hold a plain value, lowest first.
