## C1 containment

**In plain English.** C1 containment: a path is within a root exactly when it is the root itself or below it: the root's components are its first components, each compared whole. A sibling whose name extends the root's last name (/a/bc under /a/b), an ancestor of the root and an unrelated path are refused; a path that named `..` is judged where it points once resolved, so `..` never escapes.

```dafny

  ensures Contained(root, path) <==> Under(Elems(root), Elems(path))
```

```dafny
function Below(root: List<Token>, path: List<Component>): Rest {
  if root.Nil? then Inside(path)
  else if path.Nil? || root.head != path.head.name then Outside
  else Below(root.tail, path.tail)
}
```

```dafny
function Nth(ps: List<Piece>, cs: List<Component>, k: Index): Pick
  decreases cs, ps {
  if ps.Cons? then (if k == 0 then Picked(ps.head) else Nth(ps.tail, cs, k - 1))
  else if cs.Nil? then NoPick
  else Nth(cs.head.pieces, cs.tail, k)
}
```

```dafny
predicate Run(cs: List<Component>) {
  var second := Nth(Nil, cs, 1);
  Nth(Nil, cs, 0).Picked? && (second.NoPick? || (second.piece.name < 4 && Nth(Nil, cs, 2).NoPick?))
}
```

```dafny
predicate TemporaryRun(cs: List<Component>) {
  var first := Nth(Nil, cs, 0);
  var second := Nth(Nil, cs, 1);
  var fourth := Nth(Nil, cs, 3);
  first.Picked? && first.piece.scoped && second.Picked? && second.piece.name == 4 && Nth(Nil, cs, 2).Picked?
  && (fourth.NoPick? || (fourth.piece.name < 4 && Nth(Nil, cs, 4).NoPick?))
}
```

```dafny
function ArtifactAllowed(roots: Roots, path: List<Component>): bool {
  if roots.Owned? then
    var runs := Below(roots.runs, path);
    runs.Inside? && Run(runs.rest)
  else
    var temporary := Below(roots.temporary, path);
    var project := Below(roots.project, path);
    (temporary.Inside? && TemporaryRun(temporary.rest)) || (project.Inside? && Run(project.rest))
}
```

## Definitions the laws use

**Under**: Under: the root's components are the path's first components, each compared whole: the path is the root or below it.

```dafny
ghost predicate Under(root: seq<Token>, path: seq<Token>) { |root| <= |path| && path[..|root|] == root }
```

**Elems**: Elems: the items of a linked list, in order.

```dafny
ghost function Elems<T>(l: List<T>): seq<T> { if l.Nil? then [] else [l.head] + Elems(l.tail) }
```

**InRun**: InRun: the path is below the root, and the pieces below the root have the run shape.

```dafny
ghost predicate InRun(root: seq<Token>, cs: seq<Component>) {
  Under(root, Names(cs)) && RunShape(Pieces(cs[|root|..]))
```


**RunShape**: RunShape: one piece (a run directory), or two whose second is an artifact file.


**Pieces**: Pieces: the pieces of components, in order.
