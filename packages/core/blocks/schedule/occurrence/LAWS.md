## L6 classify-due

**In plain English.** L6 classify-due: if the stored next occurrence is real and due (at or before now), exactly one occurrence is acted on: dispatched under the "latest" policy, skipped under "skip". It is the latest occurrence that is due (a Witness), and the new stored next occurrence is the first one after now for an interval trigger, or none for a one-shot; a new stored next occurrence is strictly after now.

```dafny
lemma L6ClassifyDue(t: Trigger, nxt: Ms, now: Ms, p: Policy)
  requires Wf(t) && InRange(nxt) && InRange(now) && Occ(t, nxt as int) && nxt <= now
  ensures var d := Classify(t, nxt, now, p);
    (d.dispatchAt.Some? != d.skipped.Some?)
    && (d.dispatchAt.Some? <==> p == Latest)
    && (d.dispatchAt.Some? ==> Witness(t, nxt as int, now as int, d.dispatchAt.v as int))
    && (d.skipped.Some? ==> Witness(t, nxt as int, now as int, d.skipped.v as int))
    && (if t.Interval? then d.next == Next(t, now) else d.next == None)
    && (d.next.Some? ==> d.next.v > now)
```

```dafny
function Next(t: Trigger, after: Ms): Opt {
  match t
  case Once(at) => if at > after then Some(at) else None
  case Interval(a, e) => if after < a then Some(a) else Some(a + Periods(after - a, e) * e + e)
}
```

```dafny
function First(t: Trigger, now: Ms): Opt {
  match t
  case Once(at) => Some(at)
  // The first occurrence at or after now is the anchor when it is not before now, else the next one after
  // now - 1.
  case Interval(a, e) => if now <= a then Some(a) else Next(t, now - 1)
}
```

```dafny
function Classify(t: Trigger, nxt: Ms, now: Ms, p: Policy): Result {
  if nxt > now then Result(None, Some(nxt), None)
  else match t
  case Once(at) =>
    if p.Latest? then Result(Some(nxt), None, None) else Result(None, None, Some(nxt))
  case Interval(a, e) =>
    var latest := nxt + Periods(now - nxt, e) * e;
    if p.Skip? then Result(None, Some(latest + e), Some(latest))
    else Result(Some(latest), Some(latest + e), None)
}
```

## Definitions the laws use

**Wf**: Wf: a trigger is well-formed when its time is in range and, for an interval, its period is positive and at most LIMIT.

```dafny
predicate Wf(t: Trigger) {
  match t
  case Once(at) => InRange(at)
  case Interval(a, e) => InRange(a) && 0 < e <= LIMIT
}
```

**InRange**: InRange: a time within LIMIT of 1970.

```dafny
predicate InRange(x: Ms) { -LIMIT <= x <= LIMIT }
```

**Occ**: x is an occurrence of t.

```dafny
ghost predicate Occ(t: Trigger, x: int) {
  match t
  case Once(at) => x == at as int
  case Interval(a, e) => var anchor, every := a as int, e as int; exists k: nat :: x == anchor + k * every
}
```

**Witness**: Witness: L is a real occurrence of the trigger between nxt and now (inclusive), and it is the latest such occurrence: no occurrence falls after L and at or before now.

```dafny
ghost predicate Witness(t: Trigger, nxt: int, now: int, L: int) {
  Occ(t, L) && nxt <= L <= now && forall x: int | Occ(t, x) && L < x <= now :: false
}
```
