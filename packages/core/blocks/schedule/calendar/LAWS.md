## Definitions the laws use

**Wf**: Wf: every offset is within 18 hours and changes are in strictly increasing order of instant.

```dafny
predicate Wf(z: Zone) {
  -MAXOFF <= z.base <= MAXOFF
  && (forall i | 0 <= i < |z.changes| :: -MAXOFF <= z.changes[i].offset <= MAXOFF)
  && (forall i | 0 <= i < |z.changes| - 1 :: z.changes[i].at < z.changes[i + 1].at)
}
```

**WfCal**: WfCal: the local time is a minute of the day (0 to 1439) and every weekday is between 1 and 7.

```dafny
predicate WfCal(c: Calendar) {
  0 <= c.minute < 1440 && forall i | 0 <= i < |c.weekdays| :: 1 <= c.weekdays[i] <= 7
}
```

**Horizon**: Horizon: Next looks no further than 18 hours (the largest offset) before the end of the sixteenth local date after the local date of `after`; this is always more than 14 days after `after`.

```dafny
function Horizon(z: Zone, after: int): int { (LDate(z, after) + 17) * DAY - MAXOFF }
```

**LDate**: The local date at instant t, counted in days since 1970-01-01 (negative before it).

```dafny
function LDate(z: Zone, t: int): int { Local(z, t) / DAY }
```

**Local**: The local wall-clock time shown at instant t, in milliseconds of local days since 1970-01-01.

```dafny
function Local(z: Zone, t: int): int { t + Off(z, t) }
```

**Off**: The UTC offset at instant t: the offset of the last change at or before t, or the base before the first.

```dafny
function Off(z: Zone, t: int): int { OffFrom(z.base, z.changes, t) }
```

**OffFrom**

```dafny
function OffFrom(base: int, cs: seq<Change>, t: int): int
  decreases |cs|
{ if |cs| == 0 || t < cs[0].at then base else OffFrom(cs[0].offset, cs[1..], t) }
```

**Occ**: Occ: t is an occurrence of the calendar: its local date is one of the weekdays, and t is that date's occurrence of the local time.

```dafny
ghost predicate Occ(z: Zone, c: Calendar, t: int) {
  Weekday(LDate(z, t)) in c.weekdays && Earliest(z, LDate(z, t), c.minute, t)
}
```

**Weekday**: The ISO weekday of a local date: 1970-01-01 (date 0) was a Thursday (4); Monday = 1 ... Sunday = 7.

```dafny
function Weekday(d: int): int { (d + 3) % 7 + 1 }
```

**Earliest**: Earliest: t is date d's occurrence of the local time: among the instants that show date d at or after that local time, t shows the earliest local time, and t is the earliest instant showing it. So a time that occurs twice (clocks set back) is its first instance, and a time skipped by clocks set forward becomes the first local time after the jump on that date; a date with no such instant has none.

```dafny
ghost predicate Earliest(z: Zone, d: int, minute: int, t: int) {
  InDay(z, d, minute, t)
  && forall u: int | InDay(z, d, minute, u) ::
       Local(z, t) < Local(z, u) || (Local(z, t) == Local(z, u) && t <= u)
}
```

**InDay**: InDay: instant t shows local date d at or after the calendar's local time on that date.

```dafny
ghost predicate InDay(z: Zone, d: int, minute: int, t: int) {
  d * DAY + minute * MINUTE <= Local(z, t) < (d + 1) * DAY
}
```

**In**: In: t is at or after lo (when given) and shows a local time in [K, E) under offsets base-then-cs.

```dafny
ghost predicate In(base: int, cs: seq<Change>, lo: Opt, K: int, E: int, t: int) {
  (lo.None? || t >= lo.v) && K <= t + OffFrom(base, cs, t) < E
}
```

**LexLe**: Candidate a is no later than instant t by (local time, instant).

```dafny
ghost predicate LexLe(a: Cand, base: int, cs: seq<Change>, t: int) {
  a.Cand? && (a.loc < t + OffFrom(base, cs, t) || (a.loc == t + OffFrom(base, cs, t) && a.at <= t))
}
```

**Floor**: Floor: Prior looks no further back than 18 hours after the start of the sixteenth local date before the local date of `b`; this is always more than 14 days before `b`.

```dafny
function Floor(z: Zone, b: int): int { (LDate(z, b) - 16) * DAY + MAXOFF }
```
