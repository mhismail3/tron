## Definitions the laws use

**Wf**: Wf: every offset is within 18 hours, every change instant is in range, and changes are in strictly increasing order of instant.

```dafny
predicate Wf(z: Zone) { -MAXOFF <= z.base <= MAXOFF && WfChanges(z.changes) }
```

**WfChanges**

```dafny
predicate WfChanges(cs: List<Change>) {
  if cs.Nil? then true
  else if !(InRange(cs.head.at) && -MAXOFF <= cs.head.offset <= MAXOFF) then false
  else if cs.tail.Cons? && cs.tail.head.at <= cs.head.at then false
  else WfChanges(cs.tail)
}
```

**InRange**: InRange: a time within LIMIT of 1970.

```dafny
predicate InRange(x: Ms) { -LIMIT <= x <= LIMIT }
```

**WfCal**: WfCal: the local time is a minute of the day (0 to 1439) and every weekday is between 1 and 7.

```dafny
predicate WfCal(c: Calendar) { 0 <= c.minute < 1440 && WfWeekdays(c.weekdays) }
```

**WfWeekdays**

```dafny
predicate WfWeekdays(ws: List<Ms>) {
  if ws.Nil? then true else if !(1 <= ws.head <= 7) then false else WfWeekdays(ws.tail)
}
```

**Horizon**: Horizon: Next looks no further than 18 hours (the largest offset) before the end of the sixteenth local date after the local date of `after`; this is always more than 14 days after `after`.

```dafny
ghost function Horizon(z: Zone, after: int): int { (LDate(z, after) + 17) * DAY as int - MAXOFF as int }
```

**LDate**: The local date at instant t, counted in days since 1970-01-01 (negative before it).

```dafny
ghost function LDate(z: Zone, t: int): int { Local(z, t) / DAY as int }
```

**Local**: The local wall-clock time shown at instant t, in milliseconds of local days since 1970-01-01.

```dafny
ghost function Local(z: Zone, t: int): int { t + Off(z, t) }
```

**Off**: The UTC offset at instant t: the offset of the last change at or before t, or the base before the first.

```dafny
ghost function Off(z: Zone, t: int): int { OffFrom(z.base as int, z.changes, t) }
```

**OffFrom**

```dafny
ghost function OffFrom(base: int, cs: List<Change>, t: int): int
  decreases cs { if cs.Nil? || t < cs.head.at as int then base else OffFrom(cs.head.offset as int, cs.tail, t) }
```

**Earliest**: Earliest: t is date d's occurrence of the local time: among the instants that show date d at or after that local time, t shows the earliest local time, and t is the earliest instant showing it. ```dafny

```dafny
}
```
