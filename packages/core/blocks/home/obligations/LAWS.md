function Step(p: Prior, a: State, size: Count): Outcome {
  if a.request? then (if p.Present? then Contradictory else if size >= Cap then Full else Next(request))

## Definitions the laws use

**Legal**: Legal: the transitions the ledger admits. A request opens an id the ledger does not hold; reported-done closes an owed item; verified closes an owed item or one the maintainer reported done; reopened reopens a closed item.

```dafny
ghost predicate Legal(p: Prior, a: State) {
  match a
  case request => p.Absent?
  case reportedDone => p.Present? && (p.state == request || p.state == reopened)
  case verified => p.Present? && p.state != verified
  case reopened => p.Present? && (p.state == reportedDone || p.state == verified)
}
```
