## Decision in one paragraph

Prefer the **fewest independent oracles that tell the truth**. Keep a very small rendered-UI tier: the strongest verified pixel/AX prevention example is **#1607**, where all fourteen foreground journeys passed but six candidate-only visual/AX assertions remained red; production correction restored the original goldens. Do not infer that every visual red is valuable: native offset/shadow variance, intentional redesign and stale navigation dominate the other sampled lock episodes. Permit small production-logic tables for framing, classification, projection identity and units; retain actual process/socket/native tests where ownership, compilation flags, I/O, presentation or scheduling is the risk. New design needs human image review; unchanged behavior does not need another approval ceremony. These conclusions follow the incident ledger, not an imagined overall failure rate. ## Minimal tiered charter proposal

**Tier0 — build/contracts and production logic.** For a pure computation, one data-driven case calling shipped code and observing its public result is enough; allow parsers/serializers/classifiers/projection identities and deterministic work/size budgets. Do not build mock graphs, test private calls, snapshot whole objects or reassert token literals. For Swift conditional availability, compile the actual affected shipping flavor. Test only the boundary that can falsify the risk.

**Tier1 — one real integration/process journey where wiring matters.** Use actual registry/Pi/files/socket for receipts, ordering, migrations, staging, cleanup and startup/performance. Select an existing journey before adding another. Deterministic barriers own readiness; monotonic timeouts bound hangs, not ordinary scheduling assumptions. Keep one fixture owner and cleanup proof. #1596/#1606/#1694/#2031 show why pure functions cannot replace those seams. [G03–G05,I11,I15; escape table]

**Tier2 — smallest native/rendered tier.** Use one normal and one accessibility-size witness when shared layout changes; add dark only for differing appearance semantics. Assert actual control interaction, screen-space target, clipped text or contrast where that is the risk. No default all-surfaces×themes×sizes capture matrix; no endpoint image claim of motion. Keep a very small pixel parity witness for the shared chrome that actually caught #1607, pending a cheaper equally faithful replacement.

**Human approval — new design/taste/intended visible change only.** Show before/after actual candidate images for affected shared patterns, plus accessibility witness when reflow changes; batch one coherent design decision. Do not ask approval per copy of a tool-schema description, fixture relabel or unchanged rendering. Behavior-preserving moves/tweaks may skip new screenshot approval **only when their preservation proof holds**. Unexplained deltas must be diagnosed or explicitly left unqualified; never auto-bless a red golden or chase green retries.
